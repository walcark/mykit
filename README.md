# MyKit - a python library to simplify complex scientific development

This library aims to help me better organize my research workflow. It focuses on :

- **simplicity:** most scientific toolkit are generally quite verbose: logging workflows, making figures, parsing paths and loading files. `MyKit` aims to provide simple methods to facilitate those operations.
- **systematicity:** `MyKit` hopes to provide systematic workflows: naming and logging conventions, docstring, etc... The more systematic a project is, the simpler it is to analyze and integrate to other projects.
- **extendability:** scientific research projects can be diverse, thus integrating all of them into a single library would lead to disorganize and eventually cost a lot to the developper. `MyKit` aims to provide a `pack` mecanism: separate packages that rely on `MyKit`, specific to a subject.
